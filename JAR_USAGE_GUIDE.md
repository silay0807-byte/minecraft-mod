# JAR File Usage Guide\n\n## Using Pre-built JAR File\n\n### Step 1: Download Required Mods\n\n#### Minecraft Forge 47.3.0+\n1. Go to: https://files.minecraftforge.net/\n2. Select Minecraft 1.20.1\n3. Download \"Installer\" (not Universal)\n4. Run the installer\n5. Select \"Install client\"\n6. Finish installation\n\n#### TaCZ (Timeless and Classics Zero) 1.5.0+\n1. Download from:\n   - CurseForge: https://www.curseforge.com/minecraft/mods/timeless-and-classics-zero\n   - Modrinth: https://modrinth.com/mod/timeless-and-classics-zero\n2. Save the JAR file\n\n### Step 2: Locate .minecraft Folder\n\n**Windows:**\n```\nC:\\Users\\<YourUsername>\\AppData\\Roaming\\.minecraft\\mods\n```\n\n**macOS:**\n```\n~/Library/Application Support/minecraft/mods\n```\n\n**Linux:**\n```\n~/.minecraft/mods\n```\n\n### Step 3: Install Mods\n\n1. Navigate to `.minecraft/mods` folder\n2. Place these JAR files there:\n   - `timeless_and_classics_zero-1.5.0.jar` (or newer)\n   - `PancorJackhammer-1.0.0-universal.jar`\n\n### Step 4: Launch Game\n\n1. Open Minecraft Launcher\n2. In the profile dropdown, select \"forge 1.20.1\"\n3. Click \"Play\"\n4. Wait for game to load (first launch takes longer)\n\n### Step 5: Verify Installation\n\n1. In main menu, click \"Mods\"\n2. Verify both mods are listed:\n   - ✅ Timeless and Classics Zero\n   - ✅ Pancor Jackhammer\n\n## Getting the Weapon\n\n### Creative Mode\n1. Open Creative Mode inventory\n2. Search for \"pancor\" or \"jackhammer\"\n3. Grab the Pancor Jackhammer\n\n### Survival Mode\n1. Open chat (T key by default)\n2. Type: `/give @s pancor:pancor_jackhammer`\n3. Press Enter\n4. Weapon appears in inventory\n\n## Using the Weapon\n\n### Basic Controls\n- **Right Click**: Fire\n- **R Key**: Reload (default TaCZ keybind)\n- **Middle Mouse Click**: Switch fire mode\n- **Right Click + Shift**: Aim down sights\n\n### Firing\n- Fires 8 pellets in a spread pattern\n- Each pellet does damage\n- Effective range: 50 blocks\n- Spreads more at longer distances\n\n### Reloading\n1. Press R key (or configured key)\n2. Wait 4 seconds (80 ticks)\n3. Listen for reload sound\n4. Ready to fire again\n\n### Magazine\n- Capacity: 10 rounds\n- Magazine size is adjustable in config\n- Empty magazine automatically triggers reload prompt\n\n## Troubleshooting JAR Installation\n\n### \"Mod failed to load\"\n\n**Check:**\n1. Java version: `java -version` (must be 17+)\n2. Forge is installed and selected in launcher\n3. TaCZ is in mods folder\n4. File permissions (not read-only)\n5. No corrupted JAR files\n\n**Solution:**\n```\n1. Delete PancorJackhammer JAR\n2. Re-download from GitHub\n3. Place in mods folder\n4. Restart Minecraft\n```\n\n### \"Weapon doesn't appear\"\n\n**Check:**\n1. Mods are loading (check Mods menu)\n2. TaCZ is loaded\n3. Creative menu is synced (F3+T to reload)\n\n**Solution:**\n```\n1. Press F3 + T to reload resources\n2. Or restart Minecraft\n3. Verify no conflicting mods\n```\n\n### \"No sound\"\n\n**Check:**\n1. Minecraft volume not muted\n2. System volume not muted\n3. Sound files extracted properly\n\n**Solution:**\n1. Reinstall TaCZ\n2. Verify sound settings in game\n3. Update Forge version\n\n### \"Crash on startup\"\n\n**Check latest.log:**\n```\nWindows: %APPDATA%\\.minecraft\\logs\\latest.log\nLinux/Mac: ~/.minecraft/logs/latest.log\n```\n\n**Look for:**\n- \"pancor\" errors\n- \"TaCZ\" errors  \n- \"Forge\" errors\n- Java exceptions\n\n**Solutions:**\n1. Update Forge to 47.3.0+\n2. Update TaCZ to 1.5.0+\n3. Remove conflicting mods\n4. Reinstall Java 17+\n\n## Performance Optimization\n\n### Allocate More RAM\n\n**Windows:**\n1.
