# Contributing to Pancor Jackhammer

Thank you for your interest in contributing to the Pancor Jackhammer mod! This guide will help you get started.

## Code of Conduct

Please be respectful and constructive in all interactions.

## How to Contribute

### Reporting Bugs

1. Check existing issues to avoid duplicates
2. Click "New Issue"
3. Provide:
   - Clear title
   - Detailed description
   - Steps to reproduce
   - Expected vs actual behavior
   - Minecraft version, Forge version, Java version
   - Crash log (if applicable)

### Suggesting Features

1. Check existing issues first
2. Click "New Issue"
3. Clearly describe:
   - What you want added
   - Why it would be useful
   - Examples if applicable

### Submitting Changes

1. Fork the repository
2. Create a new branch: `git checkout -b feature/my-feature`
3. Make your changes
4. Follow the code style guide
5. Test thoroughly
6. Commit with clear messages: `git commit -m "Add feature description"`
7. Push to your fork
8. Create a Pull Request with detailed description

## Development Setup

See [DEVELOPMENT_GUIDE.md](DEVELOPMENT_GUIDE.md) for detailed setup instructions.

## Testing Before Submission

- [ ] Code compiles without errors
- [ ] No console warnings
- [ ] Tested in game
- [ ] Works with TaCZ
- [ ] Compatible with Forge 47.3.0+
- [ ] No memory leaks
- [ ] No breaking changes

## Code Style Guidelines

- Use 4 spaces for indentation
- camelCase for variables/methods
- PascalCase for classes
- Add Javadoc for public methods
- Keep lines under 100 characters
- No unnecessary comments

## Commit Message Format

```
<type>: <short description>

<optional detailed description>

Fixes #<issue-number> (if applicable)
```

Types:
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation
- `style`: Code style changes
- `refactor`: Code refactoring
- `perf`: Performance improvement
- `test`: Test additions

## Pull Request Process

1. Update README.md if needed
2. Update CHANGELOG.md
3. Link related issues
4. Request review from maintainers
5. Respond to feedback promptly
6. Ensure all checks pass
