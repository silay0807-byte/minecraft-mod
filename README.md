# Pancor Jackhammer - TaCZ Addon Mod

## Описание

Это полнофункциональный Forge-мод для Minecraft 1.20.1, который добавляет легендарное оружие **Pancor Jackhammer** в режиме ближнего боя.

### Особенности

✅ **3D-модель оружия** - полностью кастомная 3D-модель  
✅ **Реалистичная стрельба** - 8 дробовых картечей с разбросом  
✅ **Система перезарядки** - полная система перезарядки с звуками  
✅ **Анимации** - анимация стрельбы и перезарядки  
✅ **Звуковые эффекты** - выстрелы, перезарядка, переключение режима  
✅ **Интеграция с TaCZ** - полная поддержка Timeless and Classics Zero  
✅ **Реалистичные параметры** - урон, отдача, разброс и дальность как у настоящего Jackhammer  

## Требования

- **Minecraft**: 1.20.1
- **Forge**: 47.3.0 или выше
- **TaCZ (Timeless and Classics Zero)**: 1.5.0 или выше

## Установка

### 1. Скачайте мод
```bash
git clone https://github.com/silay0807-byte/minecraft-mod.git
cd minecraft-mod
```

### 2. Соберите проект
```bash
gradlew build
```

### 3. Найдите JAR-файл
Готовый мод находится в:
```
build/libs/PancorJackhammer-1.0.0-universal.jar
```

### 4. Установите мод
Скопируйте JAR-файл в папку:
```
.minecraft/mods/
```

## Возможные проблемы

### Мод не загружается
1. Убедитесь, что TaCZ установлен
2. Проверьте версию Forge (47.3.0+)
3. Удалите папку `.minecraft/crash-reports` и попробуйте снова

### Нет звуков
1. Проверьте, что папка `assets/pancor/sounds/` заполнена
2. Убедитесь, что звуковые файлы в формате `.ogg`

### Оружие не отображается
1. Проверьте, что JSON-файлы модели имеют правильный синтаксис
2. Убедитесь, что текстуры находятся в правильной папке
